Política de Privacidade — Gmail Email Sender

Última atualização: 10 de novembro de 2026.

Esta Política de Privacidade explica como o aplicativo desktop Gmail Email Sender (“Aplicativo”) trata informações durante a conexão com uma conta Google e o envio de mensagens por meio da Gmail API. O Aplicativo é uma ferramenta local para Windows, operada pelo próprio usuário em seu computador.

1. Responsável e contato

Para dúvidas, solicitações relacionadas a esta Política ou ao tratamento de dados pelo Aplicativo, entre em contato pelo e-mail filipepimentel.fp@gmail.com.

2. Informações tratadas pelo Aplicativo

Conforme as funções utilizadas pelo usuário, o Aplicativo pode tratar as seguintes informações:

  • Dados da conta Google autorizada: endereço de e-mail da conta conectada, utilizado para identificar a conta remetente.
  • Dados de autorização: credenciais OAuth e token de acesso/atualização emitidos pelo Google para permitir a operação autorizada. O Aplicativo solicita o escopo https://www.googleapis.com/auth/gmail.send, além dos escopos de identificação openid e email.
  • Dados da campanha: nome interno da campanha, assunto, nome do remetente e conteúdo HTML informado pelo usuário.
  • Dados dos destinatários: endereços de e-mail importados pelo usuário de arquivos CSV, além do estado do processamento, número de tentativas, data/hora do envio, identificador retornado pelo Gmail e mensagens de erro.
  • Lista de supressão: endereços que o usuário importa para impedir novos envios, por exemplo, contatos que solicitaram descadastramento ou que tiveram rejeição permanente.

O Aplicativo não solicita acesso para ler, pesquisar, excluir ou modificar mensagens da caixa de entrada, contatos, arquivos do Google Drive ou calendário. A permissão Gmail usada para a operação de envio é limitada ao escopo gmail.send.

3. Como as informações são utilizadas

As informações são utilizadas exclusivamente para executar as funções solicitadas pelo usuário, incluindo:

  • identificar a conta Google que será utilizada como remetente;
  • montar e enviar, por meio da Gmail API, uma mensagem individual para cada endereço selecionado pelo usuário;
  • manter uma fila local de destinatários e registrar o andamento dos envios;
  • evitar o reenvio automático de mensagens já confirmadas ou cujo resultado seja incerto;
  • respeitar a lista local de supressão e gerar relatórios de processamento.

O Aplicativo não utiliza os dados obtidos por meio das APIs do Google para publicidade, criação de perfis, venda de dados, análise de conteúdo para fins próprios ou treinamento de modelos de inteligência artificial.

4. Como o Gmail e o Google processam os dados

Quando o usuário solicita o envio, o Aplicativo transmite à infraestrutura do Google, pela Gmail API, os dados necessários para realizar aquela mensagem: endereço do destinatário, endereço e nome do remetente, assunto e conteúdo da mensagem em formato HTML e texto simples. O Google processa esses dados para executar a entrega do e-mail conforme os serviços e políticas próprios do Google.

O Aplicativo também consulta o serviço de identificação OAuth do Google para obter o endereço de e-mail da conta autorizada. Não consulta o conteúdo das mensagens recebidas nem utiliza a conta para qualquer finalidade diferente das funções descritas nesta Política.

5. Armazenamento e retenção

As listas importadas, campanhas, conteúdo HTML, relatórios, estados da fila, lista de supressão e tokens OAuth são armazenados localmente no computador em que o Aplicativo é executado, principalmente na pasta data e no banco de dados SQLite do Aplicativo. O arquivo credentials.json contém a identificação da credencial OAuth criada pelo próprio usuário no Google Cloud.

O Aplicativo não mantém, por conta própria, um servidor central ou banco de dados remoto para armazenar essas informações. Os dados locais permanecem no computador até que o usuário os exclua. O usuário pode apagar os dados da campanha ou a pasta de dados para removê-los do dispositivo, observando que isso também elimina o histórico e a possibilidade de retomar a fila.

A exclusão do token local não revoga, por si só, a autorização concedida ao Google. Para revogar o acesso, o usuário deve removê-lo nas configurações da Conta Google: Permissões da Conta Google.

6. Compartilhamento e terceiros

O Aplicativo não vende, aluga nem compartilha listas de contatos com anunciantes ou corretores de dados. O único compartilhamento externo inerente à função de envio ocorre com o Google, que recebe os dados da mensagem para processá-la pela Gmail API. O conteúdo também será encaminhado pelos servidores de e-mail envolvidos na entrega ao destinatário.

O usuário pode utilizar links, imagens ou outros recursos externos no HTML que inserir. Quando um destinatário abre a mensagem, esses recursos podem ser solicitados diretamente aos respectivos servidores, sujeitos às políticas desses terceiros. O usuário é responsável pelo conteúdo e pelos recursos externos incluídos na campanha.

7. Segurança

O acesso à conta Google utiliza OAuth 2.0, sem que o Aplicativo solicite ou armazene a senha da conta Google. Os tokens e o banco de dados ficam em arquivos locais. O Aplicativo não oferece armazenamento remoto desses arquivos e não afirma que eles sejam criptografados pelo próprio Aplicativo. Por isso, o usuário deve proteger sua sessão do Windows, manter o computador atualizado, restringir o acesso à pasta do Aplicativo e não compartilhar data/token.json, credentials.json ou o banco de dados.

Nenhum método de armazenamento ou transmissão é absolutamente seguro. Em caso de suspeita de acesso indevido, o usuário deve revogar imediatamente a autorização do Aplicativo na Conta Google e apagar o token local.

8. Descadastramento e responsabilidade pelos destinatários

O Aplicativo pode inserir no rodapé da mensagem um link de e-mail para que o destinatário solicite o descadastramento. O Aplicativo não lê automaticamente as respostas recebidas nem processa automaticamente esses pedidos. O usuário que administra a campanha deve acompanhar as solicitações, importar os endereços correspondentes para a lista de supressão e não enviar novas mensagens a esses destinatários.

O usuário é responsável por importar apenas contatos cuja utilização para a comunicação pretendida tenha base legal adequada, respeitar as preferências dos destinatários, manter listas de descadastramento e rejeições permanentes e cumprir a legislação aplicável, incluindo a Lei Geral de Proteção de Dados Pessoais (LGPD).

9. Direitos dos titulares

Solicitações relacionadas a dados tratados pelo operador do Aplicativo podem ser encaminhadas ao contato indicado na Seção 1. Como os dados das campanhas ficam armazenados localmente no computador do usuário, o próprio usuário que opera o Aplicativo é quem normalmente controla sua consulta, correção e exclusão no dispositivo. Os direitos relativos ao tratamento realizado pelo Google devem ser exercidos diretamente junto ao Google, de acordo com os canais e políticas do Google.

10. Crianças e adolescentes

O Aplicativo é uma ferramenta de envio de e-mails e não foi desenvolvido especificamente para crianças. O usuário deve avaliar a legitimidade e a adequação de qualquer lista de destinatários, inclusive quando envolver dados de crianças ou adolescentes, e observar as proteções legais aplicáveis.

11. Alterações desta Política

Esta Política poderá ser atualizada para refletir alterações nas funcionalidades do Aplicativo, nos serviços utilizados ou nas exigências legais. A versão vigente será publicada nesta página com a respectiva data de atualização.

12. Uso de dados das APIs do Google — compromisso de uso limitado

O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo respeitarão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).
